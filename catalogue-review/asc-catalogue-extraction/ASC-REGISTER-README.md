# ASC Product and Image Review Register

Review-only working data for the six retained ASC catalogues.

- `asc-product-image-sku-register-review-only.csv`: 50 pilot products with original ASC codes, printed descriptions, fitment text, source page and corresponding image-review status. Proposed internal identifiers use `GW-ASC-` while the ASC supplier code remains a separate field.
- `asc-ocr-candidates-quarantined-review-only.csv`: 63 OCR candidates not yet visually verified. No internal SKU is assigned to these candidates.

**Important:** proposed internal IDs are provisional. Technical specifications and dimensions remain blank where not transcribed from the source. Prices and stock are not supplied. Product images remain preview-only with supplier watermark; rights for production use are not confirmed. No live import or merge is authorized by these files.
