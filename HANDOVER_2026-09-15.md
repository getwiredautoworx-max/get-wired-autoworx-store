### PAYMENT INTEGRATION PLAN — PAYFAST + PAYJUSTNOW

- **PayFast:** use PayFast's custom web/API integration for the existing custom-built store. PayFast provides sandbox/test support and requires secure transaction verification/ITN handling. Official documentation confirms custom integrations are supported. 
- **PayJustNow:** use its direct REST API/custom integration rather than trying to force a WooCommerce plugin into the existing custom storefront. PayJustNow's official developer documentation provides the API path and its business support confirms direct REST API integrations.
- Checkout will present payment choices such as:
  - PayFast — card/available PayFast methods
  - PayJustNow — Pay in 3 / Pay in 12 where the customer's transaction qualifies
  - Any existing approved payment method retained as applicable
- The backend must create the order first, calculate the authoritative amount server-side, create the provider transaction, redirect the customer to the provider's secure payment flow, and only mark the order/quote **PAID** after verified provider confirmation/webhook.
- No payment-provider credentials, secret keys or signing secrets will be placed in browser JavaScript.
- The existing `payment-gateway` function should be extended rather than creating a second payment system.
