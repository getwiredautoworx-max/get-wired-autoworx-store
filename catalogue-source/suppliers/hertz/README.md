# Hertz Supplier Workspace

Dedicated workspace for Hertz audio product source files and catalogue preparation, separate from Planetworld and the live Get Wired catalogue.

Folders: `incoming-xlsx/`, `processed/`, `exceptions/`, `image-matches/`, and `handover/`.

The Hertz workbook previously supplied in chat is a source to inspect, not permission to publish its raw contents. Map actual models to correct product types/categories and manufacturer images. Flag uncertain matches rather than guessing. Do not commit confidential price lists to this public repository.
