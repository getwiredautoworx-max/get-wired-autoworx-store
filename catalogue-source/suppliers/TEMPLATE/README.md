# New Supplier Workspace Template

Copy this structure for each supplier and rename TEMPLATE to a stable lowercase supplier slug. Required folders: `incoming-xlsx/`, `processed/`, `exceptions/`, `image-matches/`, and `handover/`.

Never commit original supplier workbooks, confidential prices, discounts, trading terms, or account data to this public repository. Use private intake and commit only sanitized, approved outputs. Keep each supplier isolated and record real processing results.
