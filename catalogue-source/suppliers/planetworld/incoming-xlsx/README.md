# Planetworld — incoming XLSX workspace

**Folder purpose:** keep the Planetworld XLSX upload location clearly separated from the storefront code and other suppliers.

## Upload location
Place owner-approved, non-confidential XLSX files for this supplier in this folder.

## Important before uploading
The GitHub repository must be confirmed **private** before placing original supplier price lists here. If the repository is public, do not upload raw Planetworld workbooks containing dealer costs, wholesale prices, discount terms, stock feeds, account identifiers or confidential trading terms. Keep the original workbook private and upload it directly to the authorised working chat/storage for processing instead.

## Processing plan
1. Inspect every worksheet and the real column headers.
2. Map actual rows into supported audio/video segments, brands and component types.
3. Preserve exact supplier model/SKU in the private working data.
4. Match images to exact manufacturer model numbers; mark unresolved matches rather than guessing.
5. Produce an exceptions report and an owner-approved, sanitised customer-facing dataset.
6. Keep this supplier data separate from the main live store until explicit integration approval.

No supplier workbook or products are currently included in this folder. This README exists to establish the folder path.
