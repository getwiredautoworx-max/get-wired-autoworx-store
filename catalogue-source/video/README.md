# Video and home-entertainment catalogue source workspace

Use this directory for owner-approved, non-confidential working extracts and matching reports from incoming video/home-entertainment XLSX files. Create supplier/brand subfolders as each source arrives, for example `catalogue-source/video/<brand>/`.

This repository is public: do not commit raw supplier price lists or files containing dealer cost, wholesale pricing, discounts, supplier stock, account details, or confidential terms. Keep original workbooks in this chat/private authorised storage and add only an owner-approved sanitised extract or matching report safe for public disclosure.

Classify products by exact model and supported use-case; verify product imagery against the official manufacturer source. Research files do not authorise live catalogue, price, or stock changes.
