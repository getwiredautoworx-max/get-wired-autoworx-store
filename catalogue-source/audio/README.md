# Audio catalogue source workspace

This directory organises approved, non-confidential audio catalogue working files by supplier/brand.

## Subfolders
- `hertz/` — Hertz car-audio source/matching workspace.
- Add another supplier/brand subfolder when its workbook is provided.

## Important privacy rule
This repository is public. Do **not** commit original supplier XLSX/price lists containing dealer cost, wholesale pricing, discounts, supplier stock, account details, or confidential terms. Keep raw workbooks in this chat/private authorised storage. Only add an owner-approved, sanitised extract or matching report that is safe for public disclosure. Do not put supplier costs/prices into public files.

Classification and manufacturer-image matching are research-only; no live store catalogue, price, or stock changes are authorised by these files.
