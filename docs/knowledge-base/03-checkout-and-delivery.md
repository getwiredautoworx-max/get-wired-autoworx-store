# 03. Checkout and Delivery

## Checkout safety
- Test the live checkout in a non-payment / no-charge path before release. Never place a real payment merely to test the page.
- Do not describe PayFast or PayJustNow as available until the merchant has confirmed approval and a successful, authorized end-to-end test.
- Keep orders with unconfirmed stock, fitment, price, or delivery costs on hold for manual confirmation.

## Collection and delivery
- Collection is intended to be free, subject to confirming the current checkout wording.
- Courier and locker prices can vary by parcel size, weight, route, and provider. Do not publish a fixed nationwide delivery promise without a current, verified rate table.
- Where the checkout cannot calculate a reliable delivery amount, obtain and communicate a separate quote before taking payment.
- Retain order reference, delivery option, quoted amount, customer approval, and tracking evidence.

## Release checks
- Verify totals, quantity changes, delivery option, order confirmation, and mobile layout.
- Confirm no supplier cost, private SKU, API key, or internal review note appears in customer-facing pages.
- This document is an operating guide, not proof that a payment gateway or courier integration is active.
