Owner-approved working scope (18 November 2026): **Audio & Entertainment only**.

This repository contains the Get Wired AutoWorx storefront shell and its supporting application infrastructure. The active catalogue scope is limited to audio and entertainment products, categories, subcategories, approved images and audio supplier evidence.

Keep the storefront branding, homepage, cart, checkout, customer and admin functionality, Supabase integration and security controls. Non-audio catalogue material is being removed from the active working tree.
