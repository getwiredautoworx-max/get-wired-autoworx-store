## C. Verified live catalogue source

Main-branch storefront code was inspected:
- `store.html` embeds `index-new.html`.
- `index-new.html` uses Supabase project `https://ojytykqpvonxvepprgbh.supabase.co`.
- The storefront calls the Supabase REST API for active `products` and active `categories`; the product query includes `category_id`, `name`, `public_sku`, `description`, `price`, `stock_quantity`, `image_url`, `gallery_urls`, `specifications`, `compatible_vehicles`, and `featured`. Both queries filter `active=eq.true`.
- Therefore the current customer-facing catalogue data comes from Supabase, while GitHub holds the storefront client code. It is not only a static JSON catalogue.
- Previous read-only inventory snapshot: 4,198 products (4,187 active), 242 categories (165 active). Recheck counts before any action.
- Product/category relationships and dependencies include order items, vehicle compatibility, opportunities, supplier stock, competitor prices, vehicle search index, marine search index and quote/supplier-related tables. No blanket TRUNCATE/delete is safe.
