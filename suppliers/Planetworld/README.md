# Planetworld Supplier Workspace

Private workspace for authorized Planetworld price lists, audio/video XLSX files, manufacturer/model references, and working outputs.

## Pricing benchmark — owner instruction, 2026-10-26
- Use Planet World Recommended Retail Price (RRP) as the benchmark.
- Competitive target may be set 1–2 percentage points below RRP, subject to verified cost, VAT, margin, and any supplier/dealer restrictions.
- This is a working benchmark only: do not publish or import prices into the live storefront without explicit approval.

## Workflow
1. Keep original supplier files unchanged in this folder, using dated filenames.
2. Match exact manufacturer/model numbers before associating manufacturer images.
3. Sort into relevant categories (e.g. home theatre, car audio, studio, marine) and components (e.g. speakers, amplifiers).
4. Flag uncertain model/image matches rather than guessing.
5. Do not reconcile supplier stock or change live catalogue/stock while supplier authorization is pending.
