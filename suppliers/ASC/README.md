# ASC Supplier Workspace

Private supplier workspace for authorized ASC supplier files and related working notes.

- Do not import or reconcile supplier stock/prices until the owner confirms supplier authorization.
- Current in-store stock may be used for testing only; do not alter live stock/catalogue data.
- Store authorized source files in this folder, preserving original filenames and dates.
- Record source provenance and any approved transformations; do not publish dealer costs or confidential files to the storefront.
